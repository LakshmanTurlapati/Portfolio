| T-13-06 | Tampering | openProject slug lookup | mitigate | Lookup uses `projects.find()` against a hardcoded array from projects.ts — an attacker-controlled slug that does not match any project simply results in no-op (no setSelectedProject call) |
| T-13-07 | Tampering | scrollTo selector injection | mitigate | Selector is stripped of `#` and matched against a hardcoded idMap — only 'about', 'experience', 'academics' pass through; all other values produce no scroll |
