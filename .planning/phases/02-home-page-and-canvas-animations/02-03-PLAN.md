**Role Roller (shared between desktop and mobile):**

Extract as internal helper component or inline:

1. State: `currentIndex` via useState -- increments every 1 second
2. Timer: `setInterval(1000)` to advance index, cleaned up on unmount
3. Visual offset: `translateY` based on currentIndex
4. For infinite looping: render enough copies of ROLES (e.g., 3 copies) and when index reaches the end of first copy, reset index to 0 without animation (or use modular arithmetic with enough buffer items)

**Proper infinite loop approach:**
- Render `ROLES` repeated 3 times: `[...ROLES, ...ROLES, ...ROLES]`
- Track currentIndex that always increments
- When `currentIndex >= ROLES.length`, on the NEXT tick, instantly (no transition) reset to 0 and re-enable transition
- Better approach: always increment, use `currentIndex % (ROLES.length * 3)` for position, and when crossing a boundary, reset without transition

**Simplest correct approach:**
```typescript
const [currentIndex, setCurrentIndex] = useState(0);
const [isTransitioning, setIsTransitioning] = useState(true);
const totalItems = ROLES.length;

useEffect(() => {
  const interval = setInterval(() => {
    setCurrentIndex(prev => prev + 1);
  }, 1000);
  return () => clearInterval(interval);
}, []);

// When we've scrolled past the first copy, instantly reset
useEffect(() => {
  if (currentIndex === totalItems) {
    // After the transition animation completes (500ms), snap back
    const timeout = setTimeout(() => {
      setIsTransitioning(false);
      setCurrentIndex(0);
      // Re-enable transition after a frame
      requestAnimationFrame(() => {
        requestAnimationFrame(() => {
          setIsTransitioning(true);
        });
      });
    }, 500);
    return () => clearTimeout(timeout);
  }
}, [currentIndex, totalItems]);
```
