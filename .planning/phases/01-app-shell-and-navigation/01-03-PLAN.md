**Step 1: Create `src/components/portfolio-button.tsx`** -- Animated gradient glow button.

This is a `'use client'` component used in both desktop and mobile navbars.

Props:
```typescript
interface PortfolioButtonProps {
  variant: 'desktop' | 'mobile';
  isDark: boolean;
  className?: string;
}
```

Desktop variant:
- Width: 200px (fills left portion of navbar)
- Height: full parent height (60px from navbar)
- Outer border-radius: 25px (matches navbar)
- Inner button: 95% width, 80% height, border-radius 20px
- Inner button bg: var(--color-portfolio-btn-bg)
- Text: "Portfolio" at 18px, weight 600, color var(--color-portfolio-btn-text)
- Wraps content in Next.js `Link` to `/portfolio`

Mobile variant:
- Width: flex 2 of parent
- Inner button: 90% width, 80% height
- Uses Image instead of text:
  - Dark mode: `/icons/portfolio_light.png` (white text version)
  - Mobile light mode: `/icons/portfolio.png` (dark text version)
  - Image scale: 1.4x (use `width` and `height` props on Image, or CSS transform scale)
- Wraps content in Next.js `Link` to `/portfolio`

Glow animation (both variants):
- Use `requestAnimationFrame` with `useRef` for angle tracking
- 3 box-shadows rotating in a circle:
  - Blue: rgba(0, 43, 255, 0.4) -- `#002BFF` at 0.4 opacity
  - Cyan: rgba(0, 255, 204, 0.4) -- `#00FFCC` at 0.4 opacity
  - Pink: rgba(255, 74, 213, 0.4) -- `#FF4AD5` at 0.4 opacity
- Each shadow offset by 120 degrees (2*PI/3 radians)
- Orbit radius: 4px
- Blur: 18px, spread: 1px
- Full rotation: 3 seconds
- Animation rate: `(2 * Math.PI) / (3 * 60)` radians per frame at 60fps
- Apply to the OUTER container div (the glow container), not the inner button
- Update `element.style.boxShadow` directly via ref

```typescript
useEffect(() => {
  const angleRef = { current: 0 };
  let frameId: number;

  const animate = () => {
    angleRef.current += (2 * Math.PI) / (3 * 60);
    const t = angleRef.current;
    const r = 4;

    const shadows = [
      `${r * Math.cos(t)}px ${r * Math.sin(t)}px 18px 1px rgba(0, 43, 255, 0.4)`,
      `${r * Math.cos(t + 2.094)}px ${r * Math.sin(t + 2.094)}px 18px 1px rgba(0, 255, 204, 0.4)`,
      `${r * Math.cos(t + 4.189)}px ${r * Math.sin(t + 4.189)}px 18px 1px rgba(255, 74, 213, 0.4)`,
    ].join(', ');

    if (glowRef.current) {
      glowRef.current.style.boxShadow = shadows;
    }
    frameId = requestAnimationFrame(animate);
  };

  frameId = requestAnimationFrame(animate);
  return () => cancelAnimationFrame(frameId);
}, []);
```

Cleanup: cancelAnimationFrame in useEffect cleanup to prevent memory leaks.
