# Phase 4 Plan 2: AWS Amplify Deployment Configuration

## Objective

Configure the Next.js application for production deployment on AWS Amplify with proper build settings, environment variable injection for the xAI API key, and production-ready metadata.

## Context

- @.planning/research/PITFALLS.md -- Amplify env var injection workaround

## Tasks

### Task 1: Create amplify.yml build specification and Next.js production config
type="auto"

Create the AWS Amplify build configuration file (amplify.yml) with proper build commands for Next.js 15, environment variable injection for XAI_API_KEY, and configure next.config.ts for production (output settings, image optimization, headers).

type="auto"

**Done criteria:**
