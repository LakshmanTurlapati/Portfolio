**Implementation requirements:**

1. **State:** `active`, `caption`, `transcript`, `micDenied`. Use refs for non-reactive values: `recogRef`, `speakingRef`, `detachMicRef`, `audioSourceRef` (for barge-in cancel), `historyRef` (rolling messages).

2. **localStorage persistence (per D-22):**
   - On mount: `const saved = localStorage.getItem('pf-voice-history'); if (saved) historyRef.current = JSON.parse(saved);`
   - On close: `localStorage.setItem('pf-voice-history', JSON.stringify(historyRef.current.slice(-20)))`

3. **streamTTS(text: string) — ElevenLabs streaming (per D-01, D-04):**
   - `window.VoiceBus.setState('speaking')`
   - `setCaption(text)`
   - `fetch('/api/tts', { method: 'POST', headers: {'Content-Type':'application/json'}, body: JSON.stringify({ text, voiceId: 'dMWVPH9DSxWOMrrrUso3' }) })`
   - On success: `const buffer = await res.arrayBuffer()` → `const ctx = window.VoiceBus._getCtx()` → `const decoded = await ctx.decodeAudioData(buffer)`
   - Create `AudioBufferSourceNode`, connect to `AnalyserNode` (fftSize=1024), connect analyser to `ctx.destination`
   - Store source in `audioSourceRef.current` for barge-in cancel
   - `window.VoiceBus._startLoop(analyser, 1.4)` for live RMS amplitude
   - `source.onended = () => { window.VoiceBus._stopLoop(); window.VoiceBus.setState('idle'); }`
   - `source.start()`
   - On fetch error or decodeAudioData error: fallback to `attachTTSFake` with `SpeechSynthesisUtterance`, log warning

4. **speak(text: string):** Calls `streamTTS(text)`. Returns a Promise that resolves when speaking finishes (use `source.onended` to resolve). For tour sequencing.

5. **handleUserTurn(utterance: string):**
   - `window.VoiceBus.setState('thinking'); setCaption('Thinking…')`
   - Lowercase: check `isStopIntent` → `stopAll(); return`
   - Check `isTextModeIntent` → `stopAll(); openTextChat(utterance); setActive(false); return`
   - Check `isTourIntent` → `startTour(); return`
   - Check `matchNavIntent` → `goPage(nav.page); speak(nav.say); return`
   - AI intent: append to `historyRef.current`. Build messages: system prompt + "Keep replies under 2 sentences. This is a voice channel — no markdown, no lists, no emoji. " + last 20 history. POST to `/api/chat`. Collect streamed response text (read stream as text, accumulate). Call `speak(responseText)`.
   - On error: `speak("My server's glitching. Give me a sec and try again.")`

6. **startListening() — Web Speech API (per D-05, D-06):**
   - `const SR = window.SpeechRecognition || window.webkitSpeechRecognition`
   - If no SR: `setCaption("Speech recognition isn't available in this browser. Try Chrome or Edge.")`. `window.VoiceBus.setState('idle')`. Return.
   - Config: `r.continuous = false; r.interimResults = true; r.lang = 'en-US'`
   - `r.onstart`: `window.VoiceBus.setState('listening'); setCaption('Listening…')`. Then `window.VoiceBus.attachMic().then(detach => { if (window.VoiceBus.state !== 'listening') { detach(); return; } detachMicRef.current = detach; })`
   - `r.onresult`: accumulate interim + final; `setTranscript(interim || finalT)`; if finalT: `handleUserTurn(finalT.trim())`
   - `r.onerror (e)`: if `e.error === 'not-allowed'`: `setMicDenied(true); setCaption('Mic access denied. Click to retry.')`. Else: `setCaption('Mic error: ' + e.error)`. `window.VoiceBus.setState('idle')`.
   - `r.onend`: cleanup detachMicRef; if state still 'listening': `window.VoiceBus.setState('idle')`

7. **Barge-in via energy threshold (per D-21 fallback):**
   - During `speaking` state, an `AudioContext.AnalyserNode` is already reading RMS via `VoiceBus._startLoop`. Subscribe to `window.VoiceBus.on('level', (lvl) => { if (window.VoiceBus.state === 'speaking' && (lvl as number) > 0.15) { bargeIn(); } })`
   - `bargeIn()`: cancel `audioSourceRef.current?.stop()`; call `window.VoiceBus._stopLoop()`; `window.VoiceBus.setState('listening')`; call `startListening()`

8. **stopAll():**
   - `recogRef.current?.stop()`
   - `audioSourceRef.current?.stop()`; `audioSourceRef.current = null`
   - `window.speechSynthesis?.cancel()`
   - `detachMicRef.current?.(); detachMicRef.current = null`
   - `window.VoiceBus._stopLoop()`
   - `window.VoiceBus.setState('idle')`
   - `setCaption(''); setTranscript('')`

9. **open():** `setActive(true)`; after 480ms timeout: `speak(greetMessage)` where greetMessage is `currentPage === 'home' ? "Hey, I'm Parz. I can give you a tour, or just chat. What are we doing?" : "Parz here. Ask me anything, or say take me home."`

10. **close():** `stopAll()`; persist history to localStorage; `setActive(false)`

11. **Keyboard shortcuts (per D-23):**
    - In `useEffect` (active guard): `keydown Space` (code === 'Space') → if not already listening: `startListening()`; `keyup Space` → `recogRef.current?.stop()`
    - `keydown Escape` → `close()`
    - Clean up on unmount / active=false

12. **prefers-reduced-motion (per D-24):**
    - `const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches`
    - Export `prefersReduced` in return so navbar can skip GSAP morph
    - When `prefersReduced`, cap `VoiceBus.setLevel` calls to `Math.min(level, 0.2)` — override setLevel in the barge-in listener

13. **startTour():** Iterate TOUR_STEPS sequentially. For each step: if step.page !== currentPage, call `goPage(step.page)`, await 500ms settle. Then `await speak(step.say)`. If step.call: dispatch tool action.

14. **Dependency array discipline:** All callbacks that reference mutable refs should use `useCallback` with `[]` or stable deps. `speak`, `stopAll`, `handleUserTurn`, `startListening` should be `useCallback`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mic → SpeechRecognition | Browser captures audio; final transcript is untrusted user input |
| transcript → /api/chat | Utterance forwarded as-is to Grok; keep under 2 sentences constraint |
| /api/chat response → /api/tts | AI text response piped to TTS; already validated by chat route |
| localStorage → historyRef | Loaded on mount; could be tampered by user in devtools |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-07 | Elevation of Privilege | getUserMedia auto-activation | mitigate | `attachMic()` only called inside `r.onstart` (triggered by `r.start()` which is called only from explicit `startListening()`, gated on button click) |
| T-08-08 | Tampering | localStorage history tampered by user | accept | History is display + context only; worst case is confusing AI responses; no security-sensitive data |
| T-08-09 | Denial of Service | Tour loop blocks event loop | accept | Each step uses `await speak()` which resolves on audio end; no infinite loop possible |
| T-08-10 | Information Disclosure | Voice transcript logged or persisted beyond session | mitigate | Transcripts stored in historyRef only; flushed to localStorage on close (user-controlled); no server logging of utterance content |
| T-08-11 | Spoofing | matchNavIntent regex hijacked via crafted utterance to navigate to unexpected page | accept | Navigation only routes to 'home'|'portfolio'|'about'; no dynamic URL construction; safe |
</threat_model>
