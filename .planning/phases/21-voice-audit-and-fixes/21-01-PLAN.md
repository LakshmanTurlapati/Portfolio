<action>
Apply F-01 (SSE chunk-boundary parser): replace the bare `chunk.split('\n')` reader inside `handleUserTurn` with a stream-aware buffer that keeps the trailing incomplete line between reads. Refactor the per-line handling into a `handleLine` helper and flush the residual buffer on `done`.
</action>
<acceptance_criteria>
- The reader maintains a `let buffer = ''` declared outside the read loop.
- After each read: `buffer += decoder.decode(value, { stream: true })`, then `const lines = buffer.split('\n'); buffer = lines.pop() ?? ''`, then iterate lines.
- On `done`: `buffer += decoder.decode(); if (buffer) handleLine(buffer);` before breaking.
- `data: {...}` events that span chunk boundaries are no longer dropped (verified by reasoning about the buffer contract; targeted regression test deferred to a future phase if cheap mock reader is justified).
</acceptance_criteria>
