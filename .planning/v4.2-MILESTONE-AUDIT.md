## Notes & Architectural Decisions

### MOB-03 Orphan Resolution (Phase 26)

The original MOB-03 work landed in `src/components/project-detail.tsx`, which was orphaned (not imported anywhere) since Phase 17 — the live portfolio uses `IframeViewer` for project detail rendering. Per user direction during Phase 26 verification ("iframe viewer is the final way to go. update everywhere"), the orphan was deleted in commit `06d9550`. IframeViewer's existing `inset-4 sm:inset-8` provides responsive margins; further mobile polish on IframeViewer itself is deferred to a future phase if needed.

The `ProjectDetail` TypeScript interface in `src/data/projects.ts` and the `PROJECT_DETAILS` curated data are preserved for potential future use — they are data, not components.

### Preview Overlay Correction (Post-v4.2)

GSD should not treat the old right-side ProjectDetail panel as an overlay target. Current code's project/right overlay surface is `IframeViewer`'s `PreviewControlOverlay`, rendered as `fsb-preview-control-overlay` and used for project-preview control affordances. This is separate from the global `FsbControlOverlay` that renders Parz action captions.

### DART Chat Baseline (Post-v4.2)

The DART-refined chat popup is the final design baseline. Current code implements the near-final visual shell and behavior preservation; future work should refine transitions/animations only and must not revert to the archived 420px bottom-right design spec.

### Phase 27 Inline Gap Fix

Phase 27 verification flagged `handleUserTurn` calling `goPage()` directly for navigate, bypassing dispatchToolCall and thus the runTool wrapper that emits `tool-executing`. Fixed inline in commit `6875df5` — navigate now routes through `dispatchToolCall('navigate', tc.args)`. Phase 27 effective status is `passed` despite VERIFICATION.md frontmatter still reading `gaps_found` (frontmatter not re-run; gap is resolved per the inline fix).

### Voice Wave 2 Hardening Coverage

VOICE-08's deregister contract is wired but has no current consumers in v4.2 — the provider self-installs default callbacks via useEffect, which untouches the deregister return. The contract is additive and ready for future page-scoped tool registrations.
