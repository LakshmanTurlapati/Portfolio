    Completely replace the implementation of SpotlightEffect with the CSS custom property approach from the v3 prototype.

    The new implementation:

    1. Use a single `useRef<HTMLDivElement>` for the spotlight element.
    2. In a single `useEffect`, attach a `mousemove` listener to `document`. On each move event:
       - Call `spotlightRef.current.style.setProperty('--mx', e.clientX + 'px')`
       - Call `spotlightRef.current.style.setProperty('--my', e.clientY + 'px')`
       - Set opacity to 1 (spotlight becomes visible)
    3. On `mouseleave` (document), reset `--mx` to `'50%'` and `--my` to `'50%'` and set opacity to 0.
    4. Clean up both listeners on unmount.
    5. The spotlight div uses inline CSS:
       - `position: absolute`, `inset: 0`, `pointerEvents: none`, `zIndex: 35`
       - `background: radial-gradient(circle 500px at var(--mx, 50%) var(--my, 50%), var(--color-spotlight), transparent 70%)`
       - `opacity: 0` initially (no cursor position yet)
       - `transition: opacity 0.3s ease` for smooth appearance/disappearance

    No lerp, no setInterval, no direct background mutation on a timer. The CSS `var(--mx)` and `var(--my)` update synchronously with each mousemove event for zero-lag tracking.

    The `--color-spotlight` CSS variable is already defined in globals.css for both light (`rgba(255,255,255,0.1)`) and dark (`rgba(0,0,0,0.09)`) modes — the spotlight automatically adapts to theme changes.

    Complete new file content:

    ```tsx
    'use client';

    import { useRef, useEffect } from 'react';

    export function SpotlightEffect() {
      const spotlightRef = useRef<HTMLDivElement>(null);

      useEffect(() => {
        const el = spotlightRef.current;
        if (!el) return;

        const handleMove = (e: MouseEvent) => {
          el.style.setProperty('--mx', e.clientX + 'px');
          el.style.setProperty('--my', e.clientY + 'px');
          el.style.opacity = '1';
        };

        const handleLeave = () => {
          el.style.opacity = '0';
        };

        document.addEventListener('mousemove', handleMove);
        document.addEventListener('mouseleave', handleLeave);

        return () => {
          document.removeEventListener('mousemove', handleMove);
          document.removeEventListener('mouseleave', handleLeave);
        };
      }, []);

      return (
        <div
          ref={spotlightRef}
          style={{
            position: 'absolute',
            inset: 0,
            pointerEvents: 'none',
            zIndex: 35,
            background: 'radial-gradient(circle 500px at var(--mx, 50%) var(--my, 50%), var(--color-spotlight), transparent 70%)',
            opacity: 0,
            transition: 'opacity 0.3s ease',
          }}
        />
      );
    }
    ```

    Write exactly this content to spotlight.tsx. Do not add blur filter (the v3 prototype has none; the existing blur(100px) was overly aggressive).
