**File 1: `src/hooks/use-canvas.ts`**

Create the shared canvas animation hook. This is the foundation for ParticleBackground and SnowfallEffect.

Interface:
```typescript
interface UseCanvasOptions {
  animate: (ctx: CanvasRenderingContext2D, canvas: HTMLCanvasElement, deltaTime: number) => void;
  onResize?: (width: number, height: number) => void;
  willReadFrequently?: boolean;
}
function useCanvas(options: UseCanvasOptions): React.RefObject<HTMLCanvasElement | null>;
```

Implementation requirements:
- `'use client'` directive at top
- Store `canvasRef` via `useRef<HTMLCanvasElement | null>(null)`
- Store `frameRef` via `useRef<number>(0)` for cancelAnimationFrame cleanup
- Store `lastTimeRef` via `useRef<number>(0)` for deltaTime calculation
- Store `animateRef` via `useRef(animate)` -- update `.current` each render so closure is always fresh
- In useEffect:
  - Get 2D context with `{ willReadFrequently }` option
  - Create ResizeObserver on `canvas.parentElement || canvas`
  - On resize: set `canvas.width = width * dpr`, `canvas.height = height * dpr`, call `ctx.scale(dpr, dpr)`, invoke `onResize?.(width, height)`
  - Start rAF loop: calculate deltaTime as `time - lastTimeRef.current` (default 16 on first frame), call `animateRef.current(ctx, canvas, deltaTime)`, request next frame
  - Cleanup: `cancelAnimationFrame(frameRef.current)`, `observer.disconnect()`
- Dependency array: `[willReadFrequently]` only -- onResize intentionally excluded (use ref pattern if caller needs stable reference)
- Return `canvasRef`

Create `src/components/particle-background.tsx` -- a canvas-based component rendering floating blurred gradient circles.

**Component structure:**
- `'use client'` directive
- Import `useCanvas` from `@/hooks/use-canvas`
- Import `useMediaQuery` from `@/hooks/use-media-query`
- Export `ParticleBackground` component

**Particle interface:**
```typescript
interface Particle {
  x: number;       // CSS pixels
  y: number;       // CSS pixels
  vx: number;      // velocity px/frame (-1 to +1)
  vy: number;      // velocity px/frame (-1 to +1)
  size: number;    // radius in px (80-180)
  stamp: HTMLCanvasElement;  // pre-rendered blur stamp
}
```

**Pre-rendered blur stamp function (`createBlurredCircle`):**
- Takes `size` (radius) as parameter
- `blurAmount = size / 8`
- `padding = blurAmount * 3` (for blur overflow)
- `fullSize = (size + padding) * 2`
- Create offscreen canvas at fullSize x fullSize
- Apply `ctx.filter = 'blur(${blurAmount}px)'`
- Draw radial gradient circle:
  - Center: `fullSize/2, fullSize/2`, radius 0 to `size`
  - Stops: `rgba(168, 168, 168, 0.6)` at 0.0, `rgba(140, 140, 140, 0.3)` at 0.7, `rgba(0, 0, 0, 0)` at 1.0
- Return offscreen canvas

**Initialization:**
- Desktop: 7 circles. Mobile (below 600px): 4 circles
- Use `useMediaQuery('(max-width: 599px)')` for mobile detection
- Each particle: random x (0-500), random y (0-800), random vx (-1 to +1), random vy (-1 to +1), random size (80 + Math.random() * 100)
- Create blur stamp for each particle's size once at init
- Store particles array in `useRef<Particle[]>`
- Initialize particles in the `onResize` callback (first call) or in a useEffect. Re-initialize when isMobile changes.

**Animation loop (passed to useCanvas `animate`):**
- Clear canvas: `ctx.clearRect(0, 0, canvas.width / dpr, canvas.height / dpr)` where dpr = `window.devicePixelRatio || 1`
- For each particle:
  - Update position: `x += vx`, `y += vy`
  - Edge check: if circle fully exits viewport (x + size < 0 or x - size > canvasWidth, or y + size < 0 or y - size > canvasHeight), respawn at random edge with new random velocity (-1 to +1 each axis)
  - Draw: `ctx.drawImage(particle.stamp, particle.x - stampCenterX, particle.y - stampCenterY)` -- stamp the pre-rendered blurred circle

**Render:**
```tsx
<canvas
  ref={canvasRef}
  className="absolute inset-0 w-full h-full pointer-events-none"
  style={{ zIndex: 10 }}
/>
```

- `pointer-events: none` so clicks pass through
- Absolute positioned, fills parent
- z-index: 10 per UI-SPEC layering
- Theme independence: particle colors are hardcoded (same in both light/dark modes)

Create `src/components/snowfall.tsx` -- a canvas-based component rendering three-layer snow with depth, mouse drift, and theme-aware colors.

**Snowflake interface:**
```typescript
interface Snowflake {
  x: number;       // normalized 0-1
  y: number;       // normalized 0-1
  speed: number;   // movement per frame
  size: number;    // radius in px
  drift: number;   // base horizontal drift
  opacity: number; // layer opacity
}
```

**Layer configuration (stored as constants, not state):**

| Layer | Desktop Count | Mobile Count | Speed Range | Size Range | Opacity | Blur Sigma |
|-------|--------------|--------------|-------------|------------|---------|------------|
| Back  | 50           | 25           | 0.5-1.0     | 2.0-4.0px  | 0.7     | 2.0        |
| Mid   | 70           | 35           | 0.5-1.5     | 0.5-3.0px  | 0.5     | 0.1        |
| Front | 100          | 50           | 2.0-3.0     | 1.0-2.0px  | 0.3     | 1.0        |

**Initialization:**
- Use `useMediaQuery('(max-width: 599px)')` for count selection
- Create all snowflakes with random x (0-1), y (0-1), speed within layer range, size within layer range, base drift = `(Math.random() - 0.5) * 0.002`
- Store flakes in `useRef<Snowflake[]>`
- Store driftFactor in `useRef<number>(0)` -- updated by mousemove

**Mouse drift tracking:**
- Add mousemove listener on `window` in a useEffect (with cleanup!)
- `driftFactor = ((event.clientX / window.innerWidth) - 0.5) * 2` -- normalized to [-1, 1]
- Store in `driftFactorRef.current`

**Animation loop:**
- Read snow color from CSS: `getComputedStyle(canvas).getPropertyValue('--color-snow').trim()` -- do this once per frame, not per flake
- Clear canvas
- For each snowflake:
  - `y += speed / 1000`
  - `x += drift + (driftFactorRef.current * 0.001)`
  - Wrap: if `y > 1`, reset `y = -0.05`, new random `x`; if `x > 1`, set `x = 0`; if `x < 0`, set `x = 1`
  - Convert normalized coords to canvas coords: `drawX = x * canvasWidth`, `drawY = y * canvasHeight`
  - Draw filled circle: `ctx.beginPath()`, `ctx.arc(drawX, drawY, size, 0, Math.PI * 2)`, `ctx.fillStyle` = snow color with flake's opacity, `ctx.fill()`

**Blur approach (per RESEARCH.md recommendation):**
- Use ONE canvas for all 3 layers (all flakes drawn together)
- Apply CSS `filter: blur(1px)` on the canvas element as a compromise blur
- The visual difference between per-layer blur (2.0, 0.1, 1.0) and single 1px blur is minimal at these snowflake sizes

**Render:**
```tsx
<canvas
  ref={canvasRef}
  className="absolute inset-0 w-full h-full pointer-events-none"
  style={{ zIndex: 15, filter: 'blur(1px)' }}
/>
```

- z-index: 15 per UI-SPEC layering (between particles at 10 and content at 20)
- pointer-events: none
- CSS filter blur on the canvas element (GPU-accelerated)
