## Interaction Contract

This phase has two distinct rendering modes for VoicePanel, driven by current route. These are the core visual contracts the executor must implement:

### Mode 1: Home Page (existing behavior, preserved)

- Desktop: GSAP Flip morph — navbar capsule transforms from 630×60px to 760×72px, VoicePanel fades in at 0.25s
- Mobile: CSS height transition from 70px to 140px, VoicePanel fades in at 0.25s
- Trigger: user clicks Ask Parz button (home page only per D-02)
- Both modes respect `prefers-reduced-motion`: skip GSAP animation, jump to final state

### Mode 2: Non-Home Pages (new in Phase 12)

- Desktop: Fixed-position capsule, horizontally centered, `w-[760px] h-[72px]`, `rounded-[25px]`, `z-50`. Vertical position matches existing desktop-navbar.tsx `top` value (inherited, not redeclared).
  - Background: `var(--color-navbar-bg)` (same as navbar backdrop)
  - Appears when voice session is active and user has navigated away from home
  - No morph animation — renders directly in active state (appears at full size)
  - Entrance: opacity fade-in at 0.25s ease (same `vmFadeIn` as VoicePanel interior)
- Mobile: Fixed-position capsule, `h-[72px]`, `rounded-[25px]`, `z-50`. Horizontal and vertical offsets match existing mobile-navbar.tsx values (inherited, not redeclared).
  - Background: `var(--color-navbar-bg)`
  - Same entrance: opacity fade-in 0.25s ease
  - Non-home pages have no navbar row — overlay is voice content only at 72px height

### State Persistence Behavior (no new UI, contract only)

| User Action | Visual Result |
|-------------|--------------|
| Voice active on home → navigate to portfolio | VoicePanel disappears from navbar, fixed overlay appears on portfolio at same visual state |
| Voice active on non-home → navigate to another non-home | Fixed overlay persists without re-mounting or resetting |
| Voice active on non-home → navigate back to home | Fixed overlay disappears, GSAP morph navbar reactivates |
| User closes voice (X button) on any page | Overlay/navbar voice panel disappears; VoiceBus transitions to idle |
| User says "text mode" on non-home page | Navigate to home, open ChatPopup there (D-06) |

### VoiceSessionProvider Context Shape (architecture contract for executor)

The new `VoiceSessionProvider` client component exposes via React context:

| Value | Type | Description |
|-------|------|-------------|
| voiceActive | boolean | Whether voice session is running |
| voiceProps | VoiceNavProps | Props forwarded to VoicePanel (state, caption, transcript, handlers) |
| micDenied | boolean | Whether mic permission is denied |
| openVoice | () => void | Activate voice mode |
| closeVoice | () => void | Deactivate voice mode |
| prefersReduced | boolean | Prefers-reduced-motion flag for GSAP skip |

Source: CONTEXT.md D-07, D-08; voice-controller.ts VoiceControllerResult interface

## Animation Contract

| Animation | Trigger | Duration | Easing | Reduced Motion |
|-----------|---------|----------|--------|----------------|
| GSAP Flip navbar morph (home, desktop) | voiceActive toggle | 0.45s | power2.out | Skip, jump to final |
| CSS height morph (home, mobile) | voiceActive toggle | 0.45s | cubic-bezier(.22,1,.36,1) | No change (CSS only, minimal motion) |
| VoicePanel fade-in | voice content appears | 0.25s | ease forwards | No change (opacity only) |
| VoiceOverlay appearance (non-home) | route change while voice active | 0.25s | ease | No animation (show immediately) |
| State dot blink (listening) | listening state | 0.9s | ease-in-out infinite | Pause animation via media query |
| State dot blink (thinking) | thinking state | 0.6s | ease-in-out infinite | Pause animation via media query |
| Ask Parz pulse | always | 2.2s | ease-in-out infinite | Pause animation via media query |
| VoiceWave bar scale | VoiceBus 'level' event | 0.12s | ease-out | Not applicable (canvas/rAF) |

Source: desktop-navbar.tsx (GSAP Flip), mobile-navbar.tsx (CSS transition), voice-panel.tsx (vmFadeIn, vmDotBlink), globals.css (prefers-reduced-motion rules)
