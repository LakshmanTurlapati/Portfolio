## Milestone Summary

### Key Decisions

- **MOB-03 orphan resolution:** IframeViewer is canonical project viewer; ProjectDetail orphan deleted; PROJECT_DETAILS data preserved in `src/data/projects.ts` for future use.
- **runTool payload extension:** Phase 27's caption needs forced extension of Phase 25's runTool helper. Single emission point (`{ name, args }`) feeds both voice-glow (payload-agnostic) and fsb-control-overlay (payload-aware).
- **Auto-approval of human-verify checkpoints:** Per autonomous mode, plans with manual checkpoints had checkpoints auto-approved with deferred testing recorded in per-phase HUMAN-UAT.md files.

### Issues Encountered

- **Worktree cwd drift (Phase 25):** Multiple parallel worktree agents caused orchestrator's cwd to drift into a worktree path; phase 25 plans (25-03, 25-05) were initially missed during the worktree merge cycle. Resolved by switching to sequential execution (workflow.use_worktrees=false) for waves 3+ of Phase 25 and all subsequent phases. Plans 25-03 and 25-05 were preserved as untracked files on main and committed cleanly.
- **Phase 27 navigate routing gap:** Caught by verification, fixed inline in commit `6875df5` (3-line change routing navigate through dispatchToolCall).
- **Phase 26 MOB-03 orphan:** Caught by verification — work landed in a file no consumer renders. Resolved by deleting the orphan per user direction.
