   - `https://github.com/users/LakshmanTurlapati/contributions` → `.then(r => r.text())`
   - `https://api.github.com/users/LakshmanTurlapati` with `Accept: application/vnd.github+json` → `.then(r => r.json())`
   - `https://api.github.com/users/LakshmanTurlapati/repos?per_page=100&type=owner` with same Accept header → `.then(r => r.json())`

4. Parsing algorithm (implement exactly as verified in RESEARCH.md):
   - Extract `<td>` elements: `html.matchAll(/<td[^>]+class="ContributionCalendar-day"[^>]*>/g)`
   - Extract tooltip counts: `html.matchAll(/for="(contribution-day-component-\d+-\d+)"[^>]*>([^<]+)<\/tool-tip>/g)` → match `^(\d+)\s+contribution` for count
   - Build sorted `days` array: `{ date: string, count: number }[]` sorted ascending by `data-date`
   - Total from h2: `html.match(/(\d[\d,]+)\s*\n\s*contributions/)` — parse first capture group, strip commas
   - Current streak: walk backward from today; if today has 0 contributions, start from yesterday (per Pitfall 2); break when count === 0
   - Longest streak: single pass over sorted days, track max run of consecutive count > 0
   - Total stars: `Array.isArray(reposJson) ? reposJson.reduce((s, r) => s + r.stargazers_count, 0) : FALLBACK.stars`

5. Returns `NextResponse.json({ totalContributions, currentStreak, longestStreak, repos: userJson.public_repos ?? FALLBACK.repos, stars: totalStars, yearlyCommits: totalContributions })`

6. Wraps everything in `try { ... } catch { return NextResponse.json(FALLBACK); }`

CRITICAL: Use tooltip text for contribution counts — NOT `data-level` (which is 0-4 intensity only, not count). The `data-count` attribute was removed by GitHub circa 2023; tooltip text is the verified working approach.
