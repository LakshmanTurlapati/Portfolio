### VoiceGlow Color Contract (new in Phase 13)

Per D-12 (13-CONTEXT.md). These are the ONLY new color values introduced in this phase.

| Glow State | Color | Hex | CSS box-shadow |
|------------|-------|-----|----------------|
| Listening | Blue pulse (breathing) | `#3B82F6` | `0 0 30px 10px rgba(59,130,246,0.3)` — oscillates with keyframe animation |
| Tool executing | Amber solid | `#F59E0B` | `0 0 30px 10px rgba(245,158,11,0.3)` — steady, fade-in |
| Success | Green flash | `#22C55E` | `0 0 30px 10px rgba(34,197,94,0.3)` — appears then fades out in 0.5–1s |

Accent reserved for:
- VoicePanel state dot indicator colors (idle=#8fbcff, listening=#ff8f8f, thinking=#ffd58f, speaking=#8fffb6) — these are existing, not changed in Phase 13
- VoiceGlow border states listed in the table above
- Mic denied error banner: `rgba(239,68,68,0.1)` background with `rgba(239,68,68,0.3)` border (existing in voice-panel.tsx)

## Interaction Contract

### VoiceGlow Component

A new `VoiceGlow` component is added at layout level (sibling to `VoiceOverlay` in layout.tsx).

| Behavior | Spec |
|----------|------|
| Mount | Renders as a fixed `pointer-events-none` div covering the full viewport (`inset-0 z-[60]`) with `border` or `box-shadow` driven by VoiceBus state |
| Idle / voice off | No visible glow — opacity 0 or box-shadow: none |
| Listening | Blue `#3B82F6` breathing pulse — `voiceGlowBreath` keyframe oscillates glow intensity from 0.15 to 0.35 opacity over 2s ease-in-out infinite |
| Tool executing | Amber `#F59E0B` solid glow — fades in over 200ms, held steady |
| Success | Green `#22C55E` flash — fades in over 100ms, held 500ms, fades out over 400ms. Total: 1000ms |
| Error | Red `#EF4444` steady glow — fades in over 200ms, persists until VoiceBus state changes away from error |
| Reduced motion | When `prefers-reduced-motion: reduce` — breathing animation disabled; listening state shows static blue glow at 0.25 opacity |
| Z-index | 60 (above VoiceOverlay at 50, below no UI element) |

### Tool Callback States (visual side-effects only)

The following tool actions produce visual state changes. This table documents the interaction from a UI perspective — not the implementation.

| User Intent | Visual Effect | VoiceBus State During |
|-------------|---------------|-----------------------|
| "Open [project name]" | Navigate to portfolio → project detail card slides in | thinking → tool-executing → idle |
| "Go to [page]" | Circular reveal transition fires | thinking → idle |
| "Scroll to experience/education" | About page scrolls to section | thinking → tool-executing → idle |
| "Open link" | New tab opens | thinking → tool-executing → idle |
| "Toggle theme / switch to dark/light" | Theme flips immediately, no page reload | thinking → tool-executing → idle |
| Tour mode | Auto-navigates pages, opens project, speaks each description | speaking (per step) |

Note: The "tool-executing" state is a new semantic state that maps to amber glow (VFBK-02). Whether this is a new VoiceBus state or a wrapper signal is left to Claude's discretion (noted in CONTEXT.md D-discretion).

### Tour Interaction Contract

Per D-07 (13-CONTEXT.md):
- Tour plays automatically, step-by-step, after each TTS finishes
- No pauses between steps, no user confirmation prompts
- User can barge-in or say "stop" to interrupt at any step
- Tour steps navigate pages — circular reveal transition fires for each page change
- Each successful tour step completion triggers the green success glow flash (500ms total)

### Page-Ready Signal Pattern

Per D-08 (13-CONTEXT.md):
- When a tour step navigates to a new page, tool callbacks must not execute until the destination page has registered its callbacks with VoiceSessionProvider
- The page-ready handshake prevents the existing 500ms race condition
- Visual implication: amber glow begins when tool call is queued; green flash fires only after the callback executes successfully

## Animation Keyframes

New keyframes required for VoiceGlow:

```css
/* VoiceGlow breathing pulse — listening state */
@keyframes voiceGlowBreath {
  0%, 100% { box-shadow: 0 0 20px 6px rgba(59,130,246,0.15); }
  50%       { box-shadow: 0 0 40px 14px rgba(59,130,246,0.35); }
}

/* VoiceGlow success flash — fires once then removed via JS class toggle */
@keyframes voiceGlowSuccess {
  0%   { box-shadow: 0 0 30px 10px rgba(34,197,94,0); }
  15%  { box-shadow: 0 0 30px 10px rgba(34,197,94,0.35); }
  60%  { box-shadow: 0 0 30px 10px rgba(34,197,94,0.3); }
  100% { box-shadow: 0 0 30px 10px rgba(34,197,94,0); }
}
```

Add these to `globals.css` under a `/* Phase 13: VoiceGlow */` comment section.

Animation durations:
- Breath cycle: 2s ease-in-out infinite
- Success flash total: 1000ms (forwards, not repeating)
- Fade-in for amber/red: 200ms ease
- Fade-out from success to none: handled by animation forwards + class removal
