<objective>
Extend the Phase 25 `runTool` helper in `src/lib/voice-controller.ts` so that the
`tool-executing` VoiceBus event carries a `{ name, args }` payload. Phase 27's
caption layer (Plan 02) needs the tool name and its input args to render
context-aware captions like `Opening {projectName}…` and `Navigating to {page}…`.
This is a pure plumbing change — no behavior change for existing subscribers,
no new imports, no new state.

Purpose: Unblock FSB-04 caption tracking. Phase 25 closed VOICE-09 by emitting a
plain `tool-executing` ping; FSB-04 needs the payload. The change must preserve
VOICE-09's invariant that a throwing callback does NOT abort the voice turn.

Output: Updated `runTool` signature and call sites in `dispatchToolCall`. All
existing `tool-executing` subscribers (currently `voice-glow.tsx`) keep working
because they ignore payloads.
</objective>
