Concrete implementation requirements:
- Read `process.env.PRODUCTION_BASE_URL`; if missing, print `PRODUCTION_BASE_URL is required, e.g. https://audienclature.com` to stderr and exit with code 2.
- Normalize the base URL by removing trailing slashes.

- Test text chat with POST `${baseUrl}/api/chat`, header `Content-Type: application/json`, and body exactly `{"messages":[{"role":"user","parts":[{"type":"text","text":"Say hello in one short sentence."}],"id":"gap-text-1"}],"isVoice":false}`.
- Test voice-style chat with POST `${baseUrl}/api/chat`, header `Content-Type: application/json`, and body exactly `{"messages":[{"role":"user","parts":[{"type":"text","text":"Navigate to the portfolio and say one sentence."}],"id":"gap-voice-1"}],"isVoice":true}`.
- Test STT with POST `${baseUrl}/api/stt-token`, header `Content-Type: application/json`, no body. Parse JSON and print only `token_present true` when a `token` field exists or when any top-level string value looks token-like; never print the token value.
- Test TTS with POST `${baseUrl}/api/tts`, header `Content-Type: application/json`, and body exactly `{"text":"Hello from Parz production verification","voiceId":"dMWVPH9DSxWOMrrrUso3"}`. Read the response bytes and write them to `/tmp/parz-amplify-gap-test.mp3` only when status is 200.
- For every route, print one summary line containing route name, HTTP status, content-type, and a sanitized success marker: `chat_text_stream true`, `chat_voice_stream true`, `stt_token_present true`, or `tts_mp3_signature true`.
- Treat any HTTP 503 as failure and print `route returned 503` with the route name.
- Detect MP3 success for TTS when status is 200, content-type contains `audio/mpeg`, byte length is greater than 1000, and the first bytes are either `ID3` or MPEG frame sync `0xff 0xfb` / `0xff 0xf3` / `0xff 0xf2`.
- Exit code 0 only when DNS resolves and all four tests pass; otherwise exit code 1.
- Do not log API keys, STT token values, full streamed AI output, or MP3 bytes.

| Production API → third-party AI providers | `/api/chat`, `/api/stt-token`, and `/api/tts` call xAI and ElevenLabs using server-side secrets |
