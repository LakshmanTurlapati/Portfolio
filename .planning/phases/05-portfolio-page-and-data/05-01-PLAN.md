```typescript
function parseGithubUrl(url: string): { owner: string; repo: string } | null {
  try {
    const parts = new URL(url).pathname.replace(/^\/+|\/+$/g, '').split('/');
    if (parts.length >= 2) return { owner: parts[0], repo: parts[1] };
  } catch {}
  return null;
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| component→GitHub API | Unauthenticated fetch from client — subject to rate limits and CORS |
| rendered README HTML | dangerouslySetInnerHTML with GitHub-rendered markdown — attacker could host a repo with malicious README |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | GithubPreview fetch | accept | Unauthenticated API exposes only public repo data; 60 req/hr is acceptable for a portfolio (per D-03) |
| T-05-02 | Tampering | dangerouslySetInnerHTML in GithubPreview | mitigate | Content originates from GitHub's own markdown rendering API — GitHub sanitizes the HTML output. All relative URLs rewritten to absolute before injection, preventing relative-path attacks. External links get `target="_blank" rel="noopener"` |
| T-05-03 | Denial of Service | GitHub API rate limit | accept | 60 req/hr unauthenticated; show friendly "rate limit reached" error message to user |
</threat_model>
