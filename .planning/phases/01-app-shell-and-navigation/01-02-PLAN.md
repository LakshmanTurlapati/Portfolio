**Step 1: Create `src/components/sun-icon.tsx`** -- Custom SVG sun matching Flutter's SunCirclePainter.

This is NOT a library icon. It is a custom-drawn SVG with these exact specifications from Flutter:
- SVG viewBox: 30x30
- Center circle at (15, 15) with radius 5px, stroke-width 2px, no fill
- 8 rays at 45-degree intervals (0, 45, 90, 135, 180, 225, 270, 315 degrees)
- Each ray starts at distance 9px from center (radius 5 + gap 4 = 9)
- Each ray extends `rayLength` pixels further (4px default, 6px on hover)
- So ray start = `(15 + 9 * cos(angle), 15 + 9 * sin(angle))`
- Ray end = `(15 + (9 + rayLength) * cos(angle), 15 + (9 + rayLength) * sin(angle))`
- All strokes use color from CSS variable `var(--color-sun)`
- Stroke width: 2px for all elements
- Stroke linecap: round

Props interface:
```typescript
interface SunIconProps {
  active: boolean;  // true = light mode (full color), false = dark mode (muted)
  className?: string;
}
```

The component must:
- Accept `active` prop (controls color via CSS variable -- the globals.css already handles this per theme)
- Use CSS transition on the ray lines: `transition: all 300ms ease-in-out`
- Manage hover state internally with useState
- On hover: rayLength changes from 4 to 6 (animated via CSS transition on the line coordinates)
- Use inline style or data attributes to set ray endpoint positions since SVG line coordinates need JavaScript to compute

Implementation approach for animatable rays:
- Pre-compute the 8 angles in radians: `[0, PI/4, PI/2, 3PI/4, PI, 5PI/4, 3PI/2, 7PI/4]`
- For each angle, compute x1,y1 (start) and x2,y2 (end) based on current rayLength
- Render as 8 `<line>` elements with `style={{ transition: 'all 300ms ease-in-out' }}`
- On mouseEnter set rayLength to 6, on mouseLeave set rayLength to 4

**Step 1: Create `src/components/author-name.tsx`** -- Responsive author name display.

This component renders "Lakshman Turlapati" with different styles per viewport.

Desktop (>= 600px):
- Font size: 20px
- Font weight: 600 (semibold)
- Color: var(--color-text)
- Hover effect: text-shadow with offset (2px, 2px), blur 4px, color var(--color-author-text-shadow)
- Cursor: pointer
- Positioned by parent (bottom-right: bottom 20px, right 30px)

Mobile (< 600px):
- Font size: 20px
- Font weight: 500 (medium) -- intentionally lighter than desktop
- Color: var(--color-text)
- No hover effect
- Positioned by parent (top-left: top 20px, left 20px)

Implementation:
```typescript
'use client';

import { cn } from '@/lib/cn';

interface AuthorNameProps {
  className?: string;
  variant?: 'desktop' | 'mobile';
}

export function AuthorName({ className, variant = 'desktop' }: AuthorNameProps) {
  const isDesktop = variant === 'desktop';

  return (
    <span
      className={cn(
        'text-[20px] text-[var(--color-text)] select-none',
        isDesktop
          ? 'font-semibold cursor-pointer hover:drop-shadow-[2px_2px_4px_var(--color-author-text-shadow)] transition-all duration-300'
          : 'font-medium',
        className
      )}
    >
      Lakshman Turlapati
    </span>
  );
}
```

Note: The component uses a `variant` prop rather than CSS responsive classes because the desktop and mobile versions have different font weights (600 vs 500) and different hover behaviors. The parent page will render two instances with CSS responsive visibility (`hidden sm:block` / `sm:hidden`).
