<objective>
Make the chat popup input usable on iOS Safari without keyboard/viewport jank, per MOB-02 and the locked decisions in 26-CONTEXT.md and 26-UI-SPEC.md.

Purpose: Today the input has no `inputMode`, no focus-scroll, and the wrapper ignores `safe-area-inset-bottom`. On iPhone, tapping the input pushes it behind the keyboard or under the home indicator.
