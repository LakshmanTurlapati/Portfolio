**CRITICAL: The page must become a Client Component** because it needs useState for clickCounter and useMediaQuery for responsive layout. Add `'use client'` directive.

**State management:**
```typescript
const [clickCount, setClickCount] = useState(0);
const isMobile = useMediaQuery('(max-width: 599px)');
const mounted = useMounted();
```

- `clickCount`: tracks navigation clicks. Incremented when any navigation link is clicked. The `RotatingCircularText` appears when `clickCount === 1`. Mobile arrow appears when `clickCount > 0`.
- Pass an `onNavigationClick` callback to DesktopNavbar and MobileNavbar to increment clickCount. NOTE: If the navbar components do not accept this callback, add the click tracking at the page level via an onClick on the navigation wrapper divs, or modify navbar components to accept an optional `onNavigationClick` prop.
- If navbar components cannot be modified (to keep Plan 04 scoped to page.tsx only), use a click event listener on the page that detects navigation clicks via event delegation.

**Alternative approach for clickCount without modifying navbars:**
Since the Portfolio button in desktop-navbar.tsx uses Next.js Link/router for navigation, we can detect route changes or use a simpler approach: wrap the navbar containers in a div with an onClick that increments clickCount for any click within:
```tsx
<div onClick={() => setClickCount(prev => prev + 1)}>
  <DesktopNavbar />
</div>
```
This is imprecise (counts all clicks, not just navigation) but matches the Flutter behavior where `incrementClickCounter` is called on portfolio button click. For precision, only wrap the PortfolioButton area.

**Best approach:** Since the Flutter version increments on portfolio button click specifically, and the desktop-navbar already renders PortfolioButton, the simplest approach is to detect the portfolio button click at the page level. However, since we should NOT modify desktop-navbar.tsx in this plan, use a broader click handler on the navbar wrapper. This is acceptable because in the Flutter version the counter is just a visibility trigger.

**Component layout:**
```tsx
'use client';

import { useState } from 'react';
import { useMediaQuery } from '@/hooks/use-media-query';
import { useMounted } from '@/hooks/use-mounted';
import { DesktopNavbar } from '@/components/desktop-navbar';
import { MobileNavbar } from '@/components/mobile-navbar';
import { ThemeToggle } from '@/components/theme-toggle';
import { AuthorName } from '@/components/author-name';
import { ParticleBackground } from '@/components/particle-background';
import { SnowfallEffect } from '@/components/snowfall';
import { DotMatrix } from '@/components/dot-matrix';
import { RotatingCircularText } from '@/components/rotating-circular-text';
import { SpotlightEffect } from '@/components/spotlight';
import { ScrollingText } from '@/components/scrolling-text';

export default function Home() {
  const [clickCount, setClickCount] = useState(0);
  const isMobile = useMediaQuery('(max-width: 599px)');
  const mounted = useMounted();

  if (!mounted) {
    // SSR placeholder - render minimal structure to prevent hydration mismatch
    return <main className="bg-gradient-main min-h-screen relative overflow-hidden" />;
  }

  return (
    <main className="bg-gradient-main min-h-screen relative overflow-hidden">
      {/* Layer 2: z-10 -- Particle Background */}
      <ParticleBackground />

      {/* Layer 3: z-15 -- Snowfall */}
      <SnowfallEffect />

      {/* Layer 4: z-20 -- Scrolling Text (focal point) */}
      <div className="absolute inset-0 flex items-center justify-center pointer-events-none" style={{ zIndex: 20 }}>
        <div style={{ marginTop: isMobile ? '-80px' : '-40px' }} className="pointer-events-auto">
          <ScrollingText isMobile={isMobile} clickCount={clickCount} />
        </div>
      </div>

      {/* Layer 5: z-25 -- Rotating Circular Text (desktop only, conditional) */}
      {!isMobile && (
        <div
          className="absolute pointer-events-none"
          style={{
            zIndex: 25,
            // Positioning per UI-SPEC: left: viewportWidth/2 - 270 - (0.01 * viewportWidth)
            // top: 10 - (0.05 * viewportHeight)
            // Using CSS calc for responsive positioning:
            left: 'calc(50% - 270px - 1vw)',
            top: 'calc(10px - 5vh)',
          }}
        >
          <RotatingCircularText visible={clickCount === 1} />
        </div>
      )}

      {/* Layer 6: z-30 -- Dot Matrix */}
      <div
        className="absolute left-0 right-0 flex justify-center"
        style={{
          zIndex: 30,
          bottom: isMobile ? '140px' : '160px',
        }}
      >
        <DotMatrix isMobile={isMobile} />
      </div>

      {/* Layer 7: z-30/z-50 -- Navbar */}
      {/* Desktop navbar: visible >= 600px */}
      <div className="hidden sm:block" onClick={() => setClickCount(prev => prev + 1)}>
        <DesktopNavbar />
      </div>

      {/* Mobile navbar: visible < 600px */}
      <div className="sm:hidden" onClick={() => setClickCount(prev => prev + 1)}>
        <MobileNavbar />
      </div>

      {/* Layer 8: z-30 -- Chat placeholder (Phase 3 scope, position only) */}
      {!isMobile && (
        <div
          className="absolute left-0 right-0 flex justify-center"
          style={{ zIndex: 30, bottom: '20px' }}
        >
          {/* Phase 3 will add ChatPlaceholder component here */}
          <div style={{ width: 200 }} />
        </div>
      )}

      {/* Layer 9: z-35 -- Spotlight */}
      <SpotlightEffect />

      {/* Layer 10: z-40 -- Theme Toggle */}
      {/* Desktop: bottom-left */}
      <div className="hidden sm:block fixed bottom-5 left-5 z-40">
        <ThemeToggle />
      </div>
      {/* Mobile: top-right */}
      <div className="sm:hidden fixed top-5 right-5 z-40">
        <ThemeToggle />
      </div>

      {/* Layer 11: z-40 -- Author Name */}
      {/* Desktop: bottom-right */}
      <div className="hidden sm:block fixed bottom-5 right-[30px] z-40">
        <AuthorName variant="desktop" />
      </div>
      {/* Mobile: top-left */}
      <div className="sm:hidden fixed top-5 left-5 z-40">
        <AuthorName variant="mobile" />
      </div>
    </main>
  );
}
```

**Key implementation details:**
1. SSR safety: use `useMounted()` to avoid hydration mismatch since animations are client-only
2. The `<main>` already has `bg-gradient-main` from Phase 1 (background gradient = Layer 1)
3. All canvas/overlay components handle their own z-index internally OR are wrapped in positioned divs
4. DotMatrix positioned with absolute bottom + centered flex
5. ScrollingText positioned with absolute centering + vertical offset
6. RotatingCircularText positioned with absolute + calc() for viewport-relative placement
7. ChatPlaceholder is an empty 200px div placeholder for Phase 3
8. clickCount incremented by onClick on navbar wrappers -- this drives RotatingCircularText visibility (=== 1) and mobile arrow visibility (> 0)
9. Verify that all Phase 1 elements (navbar, theme toggle, author name) remain functional
10. Verify all overlay layers do not block pointer events on interactive elements
