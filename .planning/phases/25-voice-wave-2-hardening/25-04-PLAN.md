<objective>
Add a 5000 ms guard timer in `startListening` (src/lib/voice-controller.ts:663-738) that fires if Scribe accepts the connection but never emits `SESSION_STARTED`. On fire: close the Scribe connection, set caption to "Speech service slow -- switching to fallback", call `startListeningFallback()`. Clear the guard on `SESSION_STARTED`, `AUTH_ERROR`, `ERROR`, the outer `catch` (token fetch failure), and from inside `cancelAllAudio` (so a user-initiated stop while connecting kills the timer too). Closes VOICE-06.

Purpose: Today, if Scribe accepts the WebSocket but never emits any event (silent stall observed in audit), the user is stuck in "Listening..." forever. The 5 s guard provides a bounded fallback path to Web Speech.

Output: src/lib/voice-controller.ts gains a `sessionGuardRef` ref and `clearSessionGuard()` helper; the guard is armed/cleared at all five sites; `cancelAllAudio` composes the cleanup.
