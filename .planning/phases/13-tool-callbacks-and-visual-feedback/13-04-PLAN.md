  <name>Task 2: Human verification of all Phase 13 requirements</name>

  <what-built>
    Phase 13 wires all voice tool callbacks to real page actions and adds VoiceGlow viewport border animations. Changes:
    - VoiceSessionProvider: exposes registerToolCallbacks, wires toggleTheme/openLink
    - voice-controller.ts: dispatchToolCall emits VoiceBus tool signals; startTour uses page-ready wait
    - voice-glow.tsx: new component — fixed viewport div that shows CSS box-shadow per VoiceBus state
    - globals.css: voiceGlowBreath and voiceGlowSuccess keyframes + voice-glow-* classes
    - layout.tsx: VoiceGlow mounted after VoiceOverlay
    - portfolio/page.tsx: registers openProject callback + emits page-ready
    - about/page.tsx: registers scrollTo callback + emits page-ready
  </what-built>

  <how-to-verify>
    Open http://localhost:3000 in Chrome. Open browser DevTools console. Activate voice mode by clicking the Ask Parz button in the navbar.

    **VFBK-01 (Listening glow):**
    1. Activate voice mode — Parz greets you
    2. Say nothing and wait for Parz to finish greeting — you will be in idle (no glow)
    3. Say something to trigger listening — the viewport border should show a subtle blue breathing pulse
    4. Confirm the pulse animates (oscillates) — not static, not absent
    5. PASS if blue breathing glow appears and pulses during listening state

    **VFBK-02 (Tool-executing glow):**
    1. Say "toggle theme" — observe the viewport border
    2. During the brief moment between your utterance and the theme change, a steady amber glow should appear
    3. (The transition is fast — you may need to repeat or slow-mo it; alternatively trigger TOOL-01 which is longer)
    4. PASS if any amber glow is visible (even briefly) during tool execution

    **VFBK-03 (Success glow):**
    1. Say "toggle theme" — after the theme changes, a green flash should appear on the viewport border
    2. The green flash should last ~1 second then disappear cleanly
    3. PASS if a green flash appears after a successful tool call

    **VFBK-04 (Error glow):**
    1. To trigger: close voice mode, then in the browser console type `window.VoiceBus.emit('tool-error')`
    2. A red glow should appear on the viewport border and persist
    3. Activate voice mode again to trigger a VoiceBus state change — the red glow should clear
    4. PASS if red glow appears and persists until VoiceBus state changes

    **TOOL-05 (toggleTheme):**
    1. With voice active, say "toggle theme" or "switch to dark mode"
    2. The page theme should flip immediately (dark ↔ light)
    3. PASS if theme changes on voice command

    **TOOL-04 (openLink):**
    1. This requires the AI to return an openLink tool call — ask Parz something like "open my GitHub"
    2. If Parz returns a link, a new tab should open
    3. PASS if window.open is triggered (new tab opens or popup blocker activates)
    4. NOTE: This may not trigger in every conversation — mark as PASS if no console.warn appears for openLink

    **TOOL-02 (navigate — pre-existing, verify still works):**
    1. Say "take me to portfolio" — circular reveal transition should fire to the portfolio page
    2. Say "take me to about" — should navigate to about page
    3. PASS if both navigations work

    **TOOL-01 (openProject — from portfolio page):**
    1. Navigate to http://localhost:3000/portfolio
    2. Activate voice mode (Ask Parz in navbar or VoiceOverlay)
    3. Say "open Parz-AI" — the Parz-AI project detail overlay should slide in
    4. Check console: no `[VoiceController] openProject tool called but no toolCallbacks.openProject provided` warn
    5. PASS if Parz-AI project detail overlay opens

    **TOOL-01 (openProject — cross-page navigation from home):**
    1. Navigate to http://localhost:3000 (home page)
    2. Activate voice mode
    3. Say "open Parz-AI" (or ask about the project to trigger the openProject call)
    4. Voice should navigate to portfolio page, then open Parz-AI project detail
    5. PASS if navigation + project open both happen (order matters: navigate first, then open)

    **TOOL-03 (scrollTo):**
    1. Navigate to http://localhost:3000/about
    2. Activate voice mode
    3. Say "scroll to experience" — the right panel should scroll to the Experience section
    4. Say "scroll to education" — the right panel should scroll to the Academics section
    5. Check console: no `[VoiceController] scrollTo tool called but no toolCallbacks.scrollTo provided` warn
    6. PASS if both scroll commands work

    **TOOL-06 (tour end-to-end):**
    1. Navigate to http://localhost:3000 (home page)
    2. Activate voice mode
    3. Say "give me a tour"
    4. Watch all 5 tour steps:
       - Step 1: Parz speaks about the landing page (home)
       - Step 2: Parz speaks about the particles (home)
       - Step 3: Parz navigates to portfolio and speaks about it
       - Step 4: Parz speaks about Parz-AI and the project detail overlay opens
       - Step 5: Parz navigates to about and speaks about it
    5. No race condition: project overlay should open AFTER the portfolio page is fully mounted
    6. PASS if all 5 steps complete without stalling, project opens in step 4, and tour flows smoothly
  </how-to-verify>
