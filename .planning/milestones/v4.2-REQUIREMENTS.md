## v4.2 Requirements (Final Status)

### VOICE -- Voice Hardening (Wave 2 from `21-AUDIT.md`)

- [x] **VOICE-05** (F-05): User's openTextChat call from voice does not race View Transitions across page changes. **Outcome:** VoiceBus `page-ready` event emitted from `transition-provider.tsx` at three completion sites; `voice-session-provider.tsx:108` subscribes one-shot with 1500ms safety; hardcoded 400ms setTimeout removed.
- [x] **VOICE-06** (F-06): User does not get stuck in "listening" state if Scribe stalls before `SESSION_STARTED`. **Outcome:** 5000ms `sessionGuardRef` armed in `startListening` with Web Speech fallback; cleared at 5 sites (cancelAllAudio, SESSION_STARTED, AUTH_ERROR, ERROR, outer catch).
- [x] **VOICE-07** (F-07): User does not silently lose voice playback on Safari when SpeechSynthesis drops. **Outcome:** `synthGuardRef` with worst-case timeout `Math.min(30000, Math.max(1000, text.length * 50))` ms in `streamTTS`; `wrappedFinishSynth` clears guard before delegating; `cancelAllAudio` integration.
- [x] **VOICE-08** (F-08): Voice tool callbacks unregister cleanly across page navigation. **Outcome:** `registerToolCallbacks` returns `() => void` deregister fn capturing `ownedKeys` at registration. Contract is wired and additive — no v4.2 consumer exercises it yet (provider self-installs defaults). Future page-scoped tool registrations will use it.
- [x] **VOICE-09** (F-09): A throwing tool callback does not abort the voice turn. **Outcome:** `runTool(name, args, fn)` helper at `voice-controller.ts:141-171` wraps every callback invocation with try/catch; emits `tool-executing` -> `tool-success` / `tool-error`. All 7 user tools + navigate (post-fix) routed through it.

### MOB -- Mobile UX

- [x] **MOB-01**: User experiences smooth particle background on mobile. **Outcome:** `useMediaQuery('(max-width: 768px)')` gate; particle count `isMobile ? 45 : 90`; deps array reinit on breakpoint cross.
- [x] **MOB-02**: User can type into the chat input on iOS without keyboard / viewport jank. **Outcome:** `inputMode="text"` + `enterKeyHint="send"` + `autoComplete="off"` + `onFocus` 300ms `scrollIntoView({block:'center', behavior:'smooth'})` + `paddingBottom: max(16px, env(safe-area-inset-bottom))`. Preserved verbatim into Phase 28 redesign.
- [x] **MOB-03**: User can read and interact with project-detail content on mobile without horizontal cramping. **Outcome:** Responsive padding ladder (`px-4 md:px-8 lg:px-14`), full-bleed cover image, 2-col stats grid landed in `project-detail.tsx`. **Adjustment:** Component was orphaned (not imported anywhere since Phase 17). Per user direction during verification, the orphan was deleted in commit `06d9550`. `IframeViewer` is the canonical project viewer and is already mobile-friendly via `inset-4 sm:inset-8`. Curated `PROJECT_DETAILS` data preserved in `src/data/projects.ts`.

### FSB -- Overlay Polish

- [x] **FSB-04**: User sees context-aware action captions in the FSB overlay during Parz tool actions. **Outcome:** runTool extended to emit `{ name, args }` payload on `tool-executing`; `fsb-control-overlay.tsx` subscribes with state machine (1500ms success / 3000ms error holds); per-tool resolver renders captions like "Opening {projectName}…", "Navigating to {page}…". Inline gap fix (`6875df5`) routes navigate through dispatchToolCall so all 7 tools fire captions.
- [x] **FSB-05**: User sees an FSB overlay sized appropriately for mobile. **Outcome:** `useMediaQuery('(min-width: 768px)')` gates desktop scan grid; mobile badge meets WCAG 2.5.5 (44px hit-area, 11px font, 220px min-width); existing pointer-events-none preserved.

### CHAT-UI -- Chat Redesign

- [x] **CHAT-UI-01**: User experiences a redesigned chat popup with refreshed visual / UX polish. **Outcome:** Phase 28 produced UI-SPEC.md design contract first (success criterion #1 — deliverable), then executed surface+layout (28-01), typography+color (28-02), motion+a11y (28-03). Post-v4.2, the user selected the DART-refined popup as the final visual baseline; current code is near-final visually and preserves all v4.1 behavior (send/receive, suggestion chips, loading, error, Phase 25 voice handoff, Phase 26 iOS keyboard).
