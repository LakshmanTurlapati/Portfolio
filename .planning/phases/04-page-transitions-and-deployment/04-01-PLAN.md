# Phase 04 Plan 01: Circular Reveal Transitions and AWS Amplify Deployment

## Objective

Implement circular reveal page transitions on all navigation and configure AWS Amplify deployment. The circular reveal originates from the clicked element's position, uses CSS clip-path animated via GSAP, and works with Next.js App Router navigation. AWS Amplify config ensures the app builds, deploys, and serves API routes with environment variables.

## Context

- @lib/circular_reveal_page_route.dart -- Flutter reference: 500ms duration, circular clip from startOffset expanding to viewport diagonal
- @src/components/desktop-navbar.tsx -- Desktop nav with Portfolio button and About Me link
- @src/components/mobile-navbar.tsx -- Mobile nav with same navigation points
- @src/app/portfolio/page.tsx -- Portfolio back button uses router.back()
- @src/app/about/page.tsx -- About back button uses router.back()
- @src/app/chat/page.tsx -- Chat back button uses router.push('/')
- @04-CONTEXT.md -- CSS clip-path approach, GSAP for animation, TransitionProvider at layout level

## Tasks

### Task 1: Create TransitionProvider and circular reveal overlay
type="auto"

Create a React context provider that manages page transition state and renders a fixed-position overlay div with CSS clip-path circle animation driven by GSAP.

**Implementation:**
- Create `src/providers/transition-provider.tsx` with context for transition state (isTransitioning, origin coordinates, destination path)
- Create a `navigateWithReveal(path, originRect)` function exposed via context
- Render a fixed overlay div that covers the viewport, colored to match destination page background
- Animate `clip-path: circle(0px at Xpx Ypx)` to `circle(MAXpx at Xpx Ypx)` using GSAP over 500ms
- MAX radius = sqrt(maxX^2 + maxY^2) where maxX/maxY are max distances from origin to viewport corners (matching Flutter formula)
- After animation completes, perform the actual Next.js router.push() and then reverse-animate or fade out the overlay
- Wrap in layout.tsx alongside ThemeProvider

**Done criteria:**
- TransitionProvider exists and wraps the app
- `navigateWithReveal` function available via `useTransition` hook
- Overlay renders with correct clip-path animation

### Task 2: Integrate transitions into all navigation points
type="auto"

Wire the circular reveal transition into every navigation trigger: navbar links, portfolio button, and back buttons on content pages.

**Implementation:**
- Update `src/components/desktop-navbar.tsx` to use `navigateWithReveal` instead of Next.js Link for Portfolio and About Me
- Update `src/components/mobile-navbar.tsx` similarly
- Update `src/components/portfolio-button.tsx` to capture click position via getBoundingClientRect and call navigateWithReveal
- Update `src/app/portfolio/page.tsx` back button to use navigateWithReveal with the back button's position
- Update `src/app/about/page.tsx` back button to use navigateWithReveal
- Update `src/app/chat/page.tsx` back button to use navigateWithReveal
- Browser back button should work via standard navigation (no reveal animation for popstate -- matching Flutter behavior where it uses reverse animation which we approximate with standard transition)

**Done criteria:**
- All navbar navigation triggers circular reveal
- All back buttons trigger circular reveal
- Reveal originates from clicked element position
- Standard Link behavior replaced with programmatic reveal navigation
