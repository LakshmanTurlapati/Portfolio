<task type="checkpoint:human-verify">
  <name>Task 2: Smoke test all three API routes in production</name>
  <what-built>Production build is live at https://audienclature.com with both API keys injected. All three routes need end-to-end verification.</what-built>
  <how-to-verify>
Run these three curl commands against the live production URL. Each should return a real response, not a 503.

**Test 1 — /api/chat (API-01: Grok-4-1-fast-non-reasoning):**
```
curl -s -X POST https://audienclature.com/api/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","parts":[{"type":"text","text":"Say hello in one sentence."}],"id":"t1"}],"isVoice":false}' \
  | head -c 200
```
Expected: streaming text chunks from Grok (NOT `{"error":"Chat service is not configured..."}`)

**Test 2 — /api/stt-token (API-02: ElevenLabs STT token):**
```
curl -s -X POST https://audienclature.com/api/stt-token \
  -H "Content-Type: application/json" \
  | python3 -m json.tool
```
Expected: JSON with a token field like `{"token": "..."}` and HTTP 200 (NOT `{"error":"STT not configured"}`)

**Test 3 — /api/tts (API-02: ElevenLabs TTS audio):**
```
curl -s -X POST https://audienclature.com/api/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello from Parz","voiceId":"dMWVPH9DSxWOMrrrUso3"}' \
  -o /tmp/parz-test.mp3 \
  -w "%{http_code}"
```
Expected: HTTP 200 and /tmp/parz-test.mp3 is a valid MP3 file (NOT 503 with `{"error":"TTS not configured"}`)

Verify the MP3: `file /tmp/parz-test.mp3` should return "MPEG ADTS, layer III" or similar audio format.

**If any test returns 503:** The env var is not reaching the Lambda runtime. Check the Amplify build log for the preBuild phase — confirm both echo lines ran. If the build log is missing them, the amplify.yml change may not be deployed; verify the correct commit is live.
  </how-to-verify>
